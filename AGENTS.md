# Rules for all agents (phone/cloud and desktop)

- Max works with several agents at once on phone and desktop. Coordinate through Agent Hub:
  follow `agent-hub/AGENT-INSTRUCTIONS.md` at the start and end of every task.
- Never overwrite another agent's folder or version. When in doubt, put new work in a new folder.
- Always say which branch your work is on. Work that is only on a side branch is not live until it is merged into `main`.
- Never write passwords, keys or tokens into this repo — it is public.
